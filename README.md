# HAX_RESELLER

نظام مستقل لإدارة الموزعين والأرصدة ومفاتيح الوصول، بواجهة عربية RTL وتصميم أسود وأحمر.

## الوظائف
- دخول المدير ودخول الموزع بصلاحيات منفصلة.
- إنشاء موزعين وتوليد رمز دخول عشوائي يظهر مرة واحدة.
- إضافة رصيد أو خصمه مع منع الرصيد السالب.
- إنشاء مفاتيح بمدد مختلفة وعدد أجهزة محدد.
- عرض المفاتيح وحذف مفتاح محدد أو جميع مفاتيح الموزع.
- لوحة إحصائيات للمدير.

## التشغيل
يتطلب Node.js 20 أو أحدث.

```bash
npm install
cp .env.example .env
```

عدّل ملف `.env` على الخادم فقط:
- `JWT_SECRET`: سلسلة عشوائية لا تقل عن 48 حرفاً.
- `ADMIN_USERNAME`: اسم المدير.
- `ADMIN_PASSWORD`: كلمة مرور طويلة وفريدة لا تقل عن 14 حرفاً.
- `ALLOWED_ORIGINS`: اتركه فارغاً عند تقديم الواجهة والخادم من النطاق نفسه. عند فصل الواجهة، أضف أصلها الدقيق.

ثم شغّل:

```bash
npm start
```

افتح عنوان الخدمة في المتصفح. فحص الحالة متاح في `/health`.

## حفظ البيانات
يخزن الخادم البيانات في `data/store.json` خارج مجلد الواجهة. استخدم مساحة تخزين دائمة على منصة الاستضافة، واضبط `DATA_FILE` عند الحاجة. لا ترفع مجلد `data` أو ملف `.env` إلى GitHub.

## واجهات API
- `POST /api/auth/admin/login`
- `POST /api/auth/reseller/login`
- `GET /api/admin/overview`
- `GET/POST /api/admin/resellers`
- `PATCH /api/admin/resellers/:id/balance`
- `DELETE /api/admin/resellers/:id`
- `DELETE /api/admin/keys`
- `GET /api/reseller/me`
- `GET/POST /api/reseller/keys`
- `DELETE /api/reseller/keys/:id`

جميع عمليات الإدارة تتطلب Bearer token وصلاحية مناسبة.

## التكامل الخارجي
هذا النظام ينشئ ويدير مفاتيحه داخل مخزن بياناته المستقل. لم يتم ربطه بعد بخادم التحقق الخارجي أو نظام اشتراكات Happ؛ تتم إضافة ذلك بعد تحديد واجهات API وروابطك المعتمدة.

**لا توجد كلمات مرور أو رموز API افتراضية داخل الكود.**
